# Cálculo Básico de Nómina

Aplicación de consola en C# que calcula el salario bruto de un empleado.

**Fórmula:** `Salario bruto = Horas trabajadas × Pago por hora`

## Ejecutar

```powershell
dotnet run
```

## Ejemplo

- Empleado: María Rodríguez
- Horas trabajadas: 40
- Pago por hora: 250.50
- Salario bruto: RD$10,020.00
